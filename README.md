# Smart Habit Tracker

A habit tracking web application built using HTML, CSS, and JavaScript.

## Features
- Add/Edit/Delete Habits
- Streak Tracking
- Weekly Analytics
- Search & Filter
- JSON Export
- Local Storage

## Technologies Used
- HTML5
- CSS3
- JavaScript
